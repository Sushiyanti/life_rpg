# Life RPG v1.0.0 — First Stable Release

Life RPG v1.0.0 is the project's first stable release. It packages the Phase 13
Release Candidate after its scenario, persistence, crash-recovery, and Linux
artifact validation. No new gameplay systems or persistence semantics were added
for this release cut.

## Supported platform scope

- **Linux x86_64** on Ubuntu 22.04 (Jammy) or a compatible newer distribution
  providing GTK 3 and WebKitGTK 4.1.
- Jammy/glibc 2.35 is the minimum tested baseline. Older Ubuntu releases, other
  distributions with different runtime stacks, and other CPU architectures are
  not certified.
- Windows and macOS packages are not provided or claimed. Screen-reader
  certification and formal WCAG conformance testing were not performed.

## Downloadable artifacts

The GitHub Release attaches:

- `Life RPG_1.0.0_amd64.deb`
- `Life RPG_1.0.0_amd64.AppImage`
- `SHA256SUMS`

Download all three files from the [Life RPG v1.0.0 GitHub Release](https://github.com/Sushiyanti/life_rpg/releases/tag/v1.0.0), then verify the packages in the same directory:

```sh
sha256sum --check SHA256SUMS
```

Only install an artifact if the checksum check reports `OK` for its exact filename.

## Backups and privacy

World data stays local in the per-user application data directory. User-created
backup archives are also local and **unencrypted**; treat them as sensitive files
and protect copies accordingly. The archive's SHA-256 field detects corruption
but is not a signature and does not prove who created the backup. Use the
application's verified backup/restore workflow; do not copy the live SQLite file
alone while the app is open.

## Known limitations

- No cloud sync, accounts, multiplayer, mobile support, or background scheduling.
- No supported Windows or macOS installers, older Ubuntu baseline, or non-x86_64
  Linux architecture are claimed.
- Keyboard-only first-run and Workspace navigation were exercised; screen-reader
  and formal accessibility certification were not.
- The dependency audit reported zero vulnerabilities and two existing
  informational RustSec notices: `glib 0.18.5` unsoundness
  (`RUSTSEC-2024-0429`) and unmaintained `proc-macro-error 1.0.4`
  (`RUSTSEC-2024-0370`).

For validation details, limitations, and the pre-release-candidate package
checksums, see the [Phase 13 report](docs/PHASE-13-REPORT.md).
