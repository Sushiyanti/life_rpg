## Status

**Not published.** Native Windows build and installer smoke validation succeeded, but the complete installed-application validation required for a final support claim is not yet complete.

## Validation still required before publication

The following must still be completed on the installed Windows application:

- Interactive first-run/world and Player creation.
- Version `1.0.1` observed in the UI.
- Keyboard navigation/focus.
- Representative Player, Skill/Skill Tree, Quest, Stage, Branch, Session, Content, Concept/progress, Effect, Tags, Workspace, and comments/history workflows.
- Real backup/restore and malformed-backup rejection.
- Windows path testing with spaces, Unicode, backup/temporary paths, and permissions.
- Transaction-focused abrupt termination followed by SQLite integrity and usability checks.
- Uninstall, reinstall, and post-reinstall launch.

Until those checks have evidence, Windows x64 is not advertised as released/supported.

## Signing and platform scope

The installer is **unsigned**. No signing certificate or private key was available, and SmartScreen warnings are possible.

- Linux x86_64 `v1.0.0`: existing release preserved unchanged.
- Windows x64 `v1.0.1`: prepared and partially validated, not published.
- Windows ARM64: not released or validated.
- macOS: not released or validated.
